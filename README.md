# Waveform-Generator
Waveform Generator designed to be used with Nexys 4 DDR FPGA Board with full VHDL. Interfaces with UART and also uses PMODDA1 UART externally as a DAC. Generates 4 different waveform types with 10 different frequency rates.

Waveform Types:
Sawtooth
Square
Triangle
Sine

Frequency rates:
390hz - 3900hz
